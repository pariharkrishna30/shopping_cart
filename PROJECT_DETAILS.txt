eshopping Project Details
=========================

Overview
--------
This project is a full-stack eCommerce application built with:
- Frontend: React + Vite
- Backend: Laravel REST API
- Database: MySQL
- Payments: Stripe Payment Intents

Project Structure
-----------------
- api/    Laravel backend
- web/    React frontend
- docs/   API/Postman docs

Backend Work Completed
----------------------
- Laravel API scaffolded and configured
- Sanctum-based token authentication
- User auth endpoints:
  - register
  - login
  - logout
  - current user
  - forgot password
  - reset password
- Storefront endpoints:
  - categories
  - products list with search/filter/pagination
  - featured products
  - single product detail
- Cart endpoints:
  - get cart
  - add item
  - sync guest cart
  - update quantity
  - remove item
- Checkout endpoints:
  - create Stripe payment intent
  - confirm order
- Account endpoints:
  - profile
  - update profile
  - order history
  - order detail
  - order tracking
- Admin endpoints:
  - dashboard stats
  - category CRUD
  - product CRUD
  - order status update
  - user block/unblock

Important Environment Notes
---------------------------
- Backend APP_URL should be:
  APP_URL=http://127.0.0.1:8000
- Frontend API URL should be:
  VITE_API_URL=http://127.0.0.1:8000/api

Run Commands
------------
Backend:
1. cd api
2. php artisan migrate:fresh --seed
3. php artisan storage:link
4. php artisan serve

Frontend:
1. cd web
2. npm.cmd install
3. npm.cmd run dev

Admin Access
------------
- URL: http://localhost:5173/admin
- Login first with admin demo account if redirected
